## 🚀 Setup

### 1. Create virtual environment

```bash
python -m venv venv
venv\Scripts\activate        # Windows
source venv/bin/activate     # macOS/Linux
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Configure environment

```bash
copy .env.example .env       # Windows
cp .env.example .env         # macOS/Linux
```

Edit `.env` with your MongoDB Atlas connection string.

### 4. Seed the database

```bash
python -m scripts.seed
```

### 5. Start the server

```bash
uvicorn app.main:app --reload
```

## 📡 API Endpoints

### Health (Module 1)

| Method | Endpoint           | Auth     | Description                      |
| ------ | ------------------ | -------- | -------------------------------- |
| GET    | `/`                | None     | Root — confirms API is reachable |
| GET    | `/api/v1/health`   | None     | Health check (API + DB status)   |
| GET    | `/docs`            | None     | Swagger UI (interactive docs)    |
| GET    | `/redoc`           | None     | ReDoc (alternative docs)         |

### Authentication (Module 2)

| Method | Endpoint                  | Auth     | Description                        |
| ------ | ------------------------- | -------- | ---------------------------------- |
| POST   | `/api/v1/auth/register`   | None     | Register a new farmer account      |
| POST   | `/api/v1/auth/login`      | None     | Login and get access+refresh tokens|
| POST   | `/api/v1/auth/refresh`    | None     | Exchange refresh for access token  |
| POST   | `/api/v1/auth/logout`     | Bearer   | Revoke refresh token               |
| GET    | `/api/v1/auth/me`         | Bearer   | Get current user profile           |
| GET    | `/api/v1/auth/admin-check`| Admin    | Verify admin authorization         |

### Authentication Methods

1. **Bearer Token**: `Authorization: Bearer <access_token>`
2. **HttpOnly Cookie**: Automatically set on login/register

### Roles

| Role     | Description                        |
| -------- | ---------------------------------- |
| `farmer` | Default role for registered users  |
| `admin`  | Full system access                 |

## 🏗️ Architecture Rules

1. **Routes → Services → Database** (never skip the service layer)
2. **Services have NO FastAPI dependency** (pure Python)
3. **Models** = MongoDB document shapes | **Schemas** = API I/O validation
4. **UUIDs** used as document `_id` instead of MongoDB ObjectId
5. **AI models stored separately** in `ai_models/<crop>/`
6. **Refresh tokens stored hashed** (SHA-256) in MongoDB
7. **Consistent API response format**: `{ success, message, data }`
