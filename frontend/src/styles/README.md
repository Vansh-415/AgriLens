# Design Tokens

This project uses Tailwind v4 `@theme` directives in `src/index.css`.

## Colors
- **Primary (Green)**: Used for buttons, active states, and calls to action.
- **Earth (Brown/Gray)**: Used for text, borders, and backgrounds to give an agricultural feel.

## Typography
- **Sans-serif**: `Inter`, system-ui, sans-serif

## Border Radius & Shadows
- Components use Tailwind's default `rounded-md` and `rounded-lg`.
- Elevations use `shadow-sm` and `shadow-md`.
